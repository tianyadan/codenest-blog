# 8.3 - 8.9 号总结

1. 这周简单学习了一下 Python，给我最大的感觉就是处理 Excel ，CSV 这种文档文件数据真的很方便，如果使用 Java 要写很多的代码，处理起来相当费劲，但是 Python 几行代码就搞定了，真的很爽。

2 . Python 的 FastAPI 给我的感觉是可以用，可以写简单后端项目，但是不要想着去取代 Java ，在 web 方面 Java 具有天然优势，尤其是 Java21 之后引入的协程，让并发能力更加轻量，都说之前 java 又沉又重，现在确实要改变对它的看法了 ，如果 Java 虚拟机能够再轻量一些就更好了，毕竟微服务情况下，是要启动很多个 Java 项目的，一个项目一个虚拟机，到头来会占据很多 JVM 内存， 这又让我想起来了 Go 在并发下具有极佳的优势，是为了云原生而来 ，真的很想学。 但是碍于现实原因，没有那么多时间，最终还是把精力放在了 Java+Python上面。 深耕 Java 并发，JVM 、微服务治理 & Python 数据清洗 + AI 部署落地 ，后续我可以玩一玩大模型本地部署，私有化训练大模型。
